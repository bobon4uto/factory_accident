# Controls

  Mouse

-  Left click and drag = selection

-  Right click = undo selection

- Left click on work station = assign selected workers

- mouse wheel = zoom in/out

Keyboard

- WASD/arrows/HJKL = move cursor ( replace mouse )

- hold shift to go faster

- E/Spacebar acts as a left click of a mouse

- Q acts as a right click of a mouse

- I/O =  Zoom in/out

- P = reset Zoom

# General gameplay

Drag and select workers, assign them to a station. When accident is happening on station, workers cannot be assigned to it. But you can select workers during accident and save them.

Central area is considered rest zone. You can send workers there. There are no accident in the rest zone. Also, new workers arrive at the rest zone. You can upgrade speed at which they arrive using the button above the rest zone.

Every station can have up to 4 workers active at a time.
